# 扫码点单系统 - 使用说明

## 系统组成
```
手机顾客扫码 → H5点单页 → 本机Flask服务器 → SQLite订单库
                                    ↓
                            支付成功回调 → 调用云打印API → 腾晴云打印机出小票
```

## 快速启动

```bash
cd order-system
python3 server.py
```

启动后：
- 顾客端点单页: http://<本机IP>:5000/
- 商家后台: http://<本机IP>:5000/admin

当前本机IP: **9.104.224.143**（手机需和电脑连同一个WiFi）

## 一、配置打印机（关键步骤）

打开 `config.json`，找到 `printer` 段。

### 方式A：如果打印机走云平台（推荐）
绝大多数"云打印机"（包括腾晴云这类白牌）实际是接入了**飞鹅云/易联云/芯烨云**后台。
你需要：
1. 翻打印机背面铭牌或说明书，看它要求扫哪个公众号/APP配网
2. 在对应平台注册后拿到 `user`（商户编号）、`ukey`（密钥）、`sn`（打印机序列号）
3. 填入 config.json：

```json
"printer": {
  "provider": "feieyun",
  "feieyun": {
    "user": "你的商户号",
    "ukey": "你的密钥",
    "sn": "打印机机身序列号",
    "print_num": 1
  }
}
```

### 方式B：打印机和电脑在同一WiFi（直连模式）
如果打印机支持网络打印（一般端口9100），直接填打印机IP：

```json
"printer": {
  "provider": "direct",
  "direct": {
    "host": "192.168.1.100",
    "port": 9100
  }
}
```

> 蓝牙模式：Linux服务器走蓝牙比较麻烦，**建议优先用WiFi模式**。

## 二、配置支付

当前是**模拟支付**（点确认按钮直接成功），方便先跑通流程。
正式收款需要：
- **微信支付**：需要营业执照 + 微信商户号
- **支付宝**：需要营业执照 + 支付宝商户PID

拿到商户凭据后填 config.json 的 `payment` 段，后续可对接真实支付下单接口。

## 三、生成桌台二维码

商家在桌上贴一个二维码，内容就是点单页URL。例如：
```
http://9.104.224.143:5000/
```
如果要分桌号，URL后面加 `?table=A1` 即可（后续可扩展）。

用任意二维码生成网站把这个链接转成二维码打印贴桌上。

## 四、手机外网访问（可选）

如果顾客不在店里同一WiFi下，需要把本机服务暴露到公网：
- 内网穿透：cpolar / frp / ngrok
- 例如 `cpolar http 5000` 会给你一个公网地址，把那个地址做成二维码即可

## 五、文件说明

| 文件 | 作用 |
|------|------|
| server.py | Flask后端，所有API和页面路由 |
| printer.py | 打印模块（飞鹅云API + 局域网直连） |
| config.json | 店铺名、端口、打印机、支付配置 |
| templates/index.html | 顾客点单页 |
| templates/pay.html | 支付成功页（弹订单号） |
| templates/admin.html | 商家后台（订单监控+商品管理） |
| orders.db | SQLite数据库（自动生成） |
